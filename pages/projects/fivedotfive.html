📲 핵심 기능
① 인증 플로우 — 로그인 · 회원가입 · 비밀번호 재설정
🔑
로그인부터 비밀번호 재설정까지 인증 전체 플로우를 담당. 카카오 OAuth2 소셜 로그인과 아이디·비밀번호 방식 모두 구현.
  • ·로그인 · 카카오 OAuth2 소셜 로그인
  • ·회원가입 — 아이디·이메일·닉네임 중복확인, 랜덤 닉네임 생성, 내 정보 등록
  • ·비밀번호 재설정 — 이메일 인증번호 발송 → 검증 → 재설정 3단계 플로우
  • ·JWT Access/Refresh Token 관리 · 토큰 재발급 처리
로그인 API 회원가입 API 닉네임·아이디·이메일 중복확인 비밀번호 재설정 (인증번호 발송·검증) 토큰 재발급
② 댓글 CRUD · 댓글 공개일자 설정
💬
위시보드 댓글 작성·수정·삭제와 목록 조회를 구현. 기념일(targetDate) 전까지 댓글을 잠그는 공개일자 설정 UI가 핵심.
  • ·댓글 목록 조회 · 작성 · 수정 · 삭제
  • ·비회원 댓글 비밀번호 검증 (token 기반 접근)
  • ·댓글 공개일자(targetDate) 설정 UI — 기념일 전 잠금·당일 공개 전환 처리
  • ·위시 아이템 좋아요 기능 연동
댓글 목록 조회 API 댓글 작성·수정·삭제 API 비회원 댓글 비밀번호 검증 API 위시 아이템 좋아요 API
③ 마이페이지 · 회원정보 변경
👤
내 정보 조회부터 닉네임·이메일·학교·성별·학년 각각의 변경, 비밀번호 변경, 회원 탈퇴까지 마이페이지 전체를 담당.
  • ·내 정보 조회 · 수정 (닉네임·학교·성별·학년·이메일 개별 변경)
  • ·이메일 변경 — 인증번호 발송 → 검증 2단계
  • ·비밀번호 변경 · 회원 탈퇴
  • ·로그아웃 처리 (토큰 무효화)
내 정보 조회·수정 API 닉네임·학교·성별·학년·이메일 변경 API 비밀번호 변경 API 회원 탈퇴 · 로그아웃 API
④ 랭킹 & 공지 (조회)
  • ·개인·학교(팀) 댓글 랭킹 조회 (Redis 캐시 적용)
  • ·공지사항 목록·상세 조회, 배너 목록 조회
